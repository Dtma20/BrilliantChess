 Experimento

Laboratório de duelo

Dois Stockfish jogam entre si. Um lado pode usar strict_v1 e mostrar a auditoria de cada escolha.

Como funciona

A avaliação do motor vira pontos esperados entre 0 e 1, sempre do ponto de vista de quem está a jogar. Cada candidata passa por descoberta com MultiPV e depois por uma confirmação individual — é essa confirmação que define o ranking das setas, não a ordem bruta do MultiPV.

A classificação de jogadas brilhantes usa o conjunto de regras strict_v1 deste projeto: sete portões obrigatórios, cada um com valor medido e limiar registrado. Não é uma reprodução do algoritmo do Chess.com e não deve ser lida como tal.
